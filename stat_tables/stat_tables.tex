\section{Нормальное распределение (функция Лапласа)}
\noindent\begin{minipage}[c]{.55\linewidth}
Для $U \sim N(0,1)$ в таблице дана функция Лапласа
\[
  \Phi(u) = P(0 \le U \le u) = \frac{1}{\sqrt{2\pi}}\int_0^u e^{-t^2/2}\,dt .
\]
Строка — целая часть и первый знак $u$, столбец — второй знак.
\textbf{Пример:} $\Phi(1{,}65) = 0{,}4505$, поэтому
$P(U > 1{,}65) = 0{,}5 - 0{,}4505 = 0{,}0495$.
Двусторонние критические значения: $u = 1{,}645$ при $\alpha = 10\,\%$,
$1{,}960$ при $5\,\%$, $2{,}576$ при $1\,\%$.

\section{Распределение \texorpdfstring{$\chi^2$}{хи-квадрат}}

$P\bigl(\chi^2 > \chi^2_\alpha(\nu)\bigr) = \alpha$.
\textbf{Пример:} при $\nu = 15$ $P(\chi^2 > 8{,}55) = 0{,}90$ и

$\chi^2_{0{,}05}(2) = 5{,}99$. При $\nu > 100$ величина
$\sqrt{2\chi^2} - \sqrt{2\nu - 1}$ приближённо распределена как $N(0,1)$.

\section{Критические точки Дарбина--Уотсона}
\noindent Границы $d_L$ и $d_U$ для статистики
$\mathrm{DW} = \sum_{t=2}^{n}(e_t - e_{t-1})^2 / \sum_{t=1}^{n}e_t^2$;
$n$ — число наблюдений, $m$ — число регрессоров \emph{без константы}.
Таблицы верны для регрессии с константой и без лагированной зависимой
переменной. Решение по $H_0\colon \rho = 0$: при $\mathrm{DW} < d_L$ —
положительная автокорреляция; при $d_L \le \mathrm{DW} \le d_U$ — вывода нет;
при $d_U < \mathrm{DW} < 4 - d_U$ — автокорреляции нет; при
$4 - d_U \le \mathrm{DW} \le 4 - d_L$ — вывода нет; при $\mathrm{DW} > 4 - d_L$ —
отрицательная автокорреляция.
\textbf{Пример:} $n = 24$, $m = 1$, $\alpha = 5\,\%$: $d_L = 1{,}273$,
$d_U = 1{,}446$; при $\mathrm{DW} = 1{,}103 < d_L$ есть положительная
автокорреляция.
